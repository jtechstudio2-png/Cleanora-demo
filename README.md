# Cleanora live demo

Static build of the Cleanora facility services website platform (Enterprise edition) with fictional demo content, for https://jtechstudio2-png.github.io/Cleanora-demo.

This repository contains only the published website (HTML, CSS, JavaScript, fonts and documents). The Cleanora source code is proprietary and sold separately on WiCareStore.

- The company, people, figures, case studies and certificates are fictional. The PDFs are watermarked specimens, not real certificates.
- Forms validate and show a reference number, but nothing is sent. In the product, enquiries are delivered to the buyer's CRM or webhook.

Deploy: any static host, serving this folder as the site root (no build step). On GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
